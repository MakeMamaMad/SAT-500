# SAT500 — экономика каждого рейса

Одностраничный веб-проект о полуприцепе SAT500: полезная нагрузка, WABCO/SAF, конструкция, обратная загрузка, комплектации и интерактивная экономика перевозок.

## Что внутри

- адаптивный лендинг без фреймворков и внешней сборки;
- четыре смысловых раздела перед покупкой;
- калькулятор дополнительной загрузки и окупаемости;
- отдельная модель сервисного эффекта WABCO + SAF;
- сценарий обратной загрузки;
- сравнение комплектаций и ценовых сценариев;
- лид-форма без передачи персональных данных на сторонний сервер;
- ссылки на источники и разделение фактов, расчётов и финансовых допущений;
- офлайн-фолбэки для ключевых изображений;
- скрытый режим редактирования текстов через `?edit=1`.

## Локальный запуск

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/`.

## Проверка

```bash
npm run check
```
