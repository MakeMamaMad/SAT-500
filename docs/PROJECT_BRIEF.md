# SAT500 — проект сайта

## Цель

Сделать технический продающий сайт SAT500, в котором решение о покупке строится через экономику эксплуатации, а не только через перечень характеристик.

## Основная логика страницы

1. Полезная нагрузка — эффект меньшей собственной массы.
2. Сервис — WABCO/ZF, SAF и стоимость простоев.
3. Конструкция — материал, профиль, геометрия и режим эксплуатации.
4. Обратная загрузка — влияние порожнего пробега на экономику.
5. Калькулятор — пользователь вводит собственные ставки и получает сценарный денежный эффект.
6. Комплектации — сравниваются конкретные спецификации, а не названия брендов.
7. Контактный блок — формирует запрос без отправки персональных данных на сторонний сервер.

## Принцип работы с цифрами

Факты производителя, инженерные расчёты и финансовые допущения должны быть визуально и текстово разделены. Любая цена, срок окупаемости или экономический эффект без подтверждённого коммерческого предложения считается сценарием.
